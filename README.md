# 🛒 Ecommerce Frontend (React + Vite + Tailwind CSS)

A desktop-first eCommerce frontend built using React (Vite) and Tailwind CSS.

This project was developed as a **Figma-to-code conversion task**, where the main focus was to convert a complete Figma design into a pixel-perfect frontend.

The goal was:
- 🎨 Accurate UI replication from Figma
- 📐 Proper spacing, layout, and alignment
- 🧩 Clean reusable React components
- ⚡ Fast design-to-code workflow
- 📱 Desktop-first responsive UI

---

## 🎯 Project Overview

This project was assigned as a real-world **Figma implementation task**.

The Figma file was the single source of truth, and the objective was to replicate the design as closely as possible in React.

This demonstrates:
- Strong UI conversion skills (Figma → React)
- Attention to design detail
- Component-based frontend structure
- Real-world frontend workflow experience
